# Modelling of private-car commuting energy demand

This repository contains the data and machine-learning code supporting the study:

**Spatial dimension of private-car commuting energy demand: Implications for place-based transport policy design**

The repository includes implementations of XGBoost and GPBoost models for total and per-capita private-car commuting energy demand across Small Areas in Ireland.
